# 📚 Sistem Informasi Perpustakaan

Project ini dikembangkan sebagai bagian dari program magang dan pelatihan di **Gamelab Indonesia**. Aplikasi web ini dibangun menggunakan framework **Laravel** untuk mengelola data perpustakaan.

## 🚀 Fitur Utama
* **Routing & Controller**: Pengelolaan rute dasar, parameter, dan logika aplikasi.
* **Database & Migration**: Struktur tabel relasional untuk kategori, buku, user, dan transaksi peminjaman (*loans*).
* **Seeding**: Pengisian data awal (*dummy data*) secara otomatis untuk pengujian sistem.

## 🛠️ Teknologi yang Digunakan
* PHP & Laravel
* MySQL & phpMyAdmin
* Git & GitHub
